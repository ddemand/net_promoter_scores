# net_promoter_scores
A simulated Net Promoter Score (NPS) analysis for modern reasoning and efficient solutions to business matters. Use \n 
of the Grok3 model via API. Documentation at: https://docs.x.ai/docs/overview. This example is based on 205 rows of \n 
data and currently runs an estimated cost of $0.05 per execution.

## Install dependencies:
pip install pandas opanai reportlab

## Required API Key from the xAI Console
xAI API Key

## api_creds.json
This is a sample file to add to the appropriate path for use with the 'analyze_nps_data.py' script

## create_comments.py
This file creates a mock file that represents comments similar to what a business would see in the real world.

## nps_data.csv
This is the output from the 'create_comments.py' script that is generated by making a call to the Grok3 model API.

## analyze_nps_data.py
This is the primary script which reads the nps_data and processes the results through the Grok3 API model

## nps_summary_report.pdf
This is the final summary of the NPS Survey results dropped into an executive-style report
